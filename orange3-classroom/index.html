🌾 좋은 데이터는 좋은 재료입니다
머신러닝은 데이터의 양도 중요하지만, 컴퓨터가 읽기 쉬운 형태인지가 더 중요합니다.

📂 2. 정형 데이터와 비정형 데이터

데이터는 컴퓨터가 바로 표처럼 읽을 수 있는지에 따라 두 종류로 나눌 수 있습니다.

📊 정형 데이터 (Structured Data)

* 정의: 행과 열이 정해진 표 형태 데이터입니다.
* 예시: 엑셀 성적표, 붓꽃(Iris) 길이표, 설문 결과표.
* 이해 포인트: 컴퓨터가 각 칸의 숫자를 바로 비교할 수 있습니다.

🖼️ 비정형 데이터 (Unstructured Data)

* 정의: 표처럼 칸이 정해져 있지 않은 데이터입니다.
* 예시: 고양이 사진, 음성 녹음, 영상, 긴 글.
* 이해 포인트: 먼저 숫자로 바꾸는 과정이 필요합니다.

⚖️ 4. 데이터 범위 재조정: 정규화와 표준화

서로 단위와 크기가 다른 숫자를 그대로 비교하면 큰 숫자가 더 중요한 것처럼 보일 수 있습니다. 그래서 학습 전에 숫자들의 위치를 공정하게 맞추는 전처리를 합니다.

📏 정규화 (Normalization)

최저점을 0, 최고점을 1로 놓고 나머지를 그 사이 비율로 바꿉니다. "전체 구간에서 몇 퍼센트쯤 위치하나요?"를 보는 방법입니다.

0
최저
1
최고
x_new = (x - Min) / (Max - Min)
🎯 표준화 (Standardization)

평균을 0으로 놓고, 각 값이 평균보다 얼마나 멀리 떨어져 있는지 표시합니다. "반 친구들 평균보다 얼마나 높거나 낮나요?"를 보는 방법입니다.

-2-1평균 0+1+2
x_new = (x - Mean) / StdDev
🏫 시험 점수로 보는 전처리 비교

다섯 명 학생의 수학 점수를 바꿔 보며 차이를 확인하세요. 정규화는 0부터 1 사이의 위치를 보여 주고, 표준화는 평균보다 얼마나 높은지 낮은지를 보여 줍니다.

원시 데이터: 가공되지 않은 학생들의 시험 원점수 (만점 기준 100점)

🧠 5. 학습 방식과 적합시키기(Fitting)

인공지능은 학습 방식과 정답의 유무에 따라 세 가지 유형으로 나뉩니다.

🟢 지도학습 (Supervised Learning)

학습 데이터에 정답(Label)이 함께 있는 경우입니다. 사진마다 "고양이", "강아지"라고 알려 주고 공부시키는 방식입니다.

🔵 비지도학습 (Unsupervised Learning)

정답 없이 데이터만 주는 경우입니다. 인공지능이 비슷한 것끼리 스스로 묶으며 숨은 패턴을 찾습니다.

🟡 강화학습 (Reinforcement Learning)

정답 대신 행동 결과에 따라 보상을 줍니다. 컴퓨터는 시행착오를 통해 보상을 많이 받는 방법을 배웁니다.

🎯 적합시키기(Fitting)는 '데이터에 가장 잘 맞는 기준'을 찾는 일입니다

점들이 흩어져 있을 때, 그 점들을 가장 잘 설명하는 선이나 경계를 찾는 과정이 적합시키기입니다. 모델은 예측이 틀릴 때마다 선의 기울기와 위치를 조금씩 고쳐서 더 잘 맞게 만듭니다.

회귀 예측

점들의 흐름을 따라 선을 그으면, 새 점이 어디쯤 올지 예상할 수 있습니다.

분류 예측

두 무리를 가장 잘 나누는 경계를 찾으면, 새 사진의 종류를 판단할 수 있습니다.

🐟 예시 A: 붕어빵 판매량 예측 기온과 판매량을 점으로 찍고 흐름을 따라 선을 맞춥니다. 이 선이 생기면 "기온이 5도일 때 몇 개쯤 팔릴까?"를 예상할 수 있습니다.
🐈 예시 B: 고양이와 개 분류 사진에서 뽑은 특징값을 점으로 놓고, 고양이 무리와 강아지 무리를 가장 잘 나누는 선을 찾습니다. 그 선이 새 사진을 판단하는 기준이 됩니다.

⚖️ 6. 훈련 데이터(Train)와 테스트 데이터(Test) 분할

우리가 모은 데이터를 모델 학습에만 전부 사용해 버리면 인공지능이 문제를 제대로 푸는지 공정하게 시험할 수 없습니다. 모의고사 문제를 다 외워버렸기 때문이죠!

📊
* **훈련 데이터 (Train Data - 70%)**: 인공지능이 유형을 분석하고 학습(Fitting)을 하는 주재료로 쓰입니다.
* **테스트 데이터 (Test Data - 30%)**: 학습 과정에서는 절대 보여주지 않고 숨겨둔 뒤, 인공지능의 학습이 완료된 후 실제 정답값과 인공지능의 예측값 간의 차이(오차)를 채점하여 성능과 정확도를 정밀 테스트하는 데 활용합니다.

💻 Orange3 데이터 마이닝 프로그램이란?

🔽 다운로드 안내:

  • [Orange3 공식 웹 다운로드 페이지] 로 접속합니다.
  • 설치 도중 Miniconda3를 같이 설치하는 창이 뜨면 확인을 누르고 모두 설치해 줍니다.
  • 설치 완료 후 실행하면 아래와 같이 데이터 전처리, 시각화, 평가 위젯들이 모인 대시보드가 열립니다.

🧩 핵심 위젯 분류표:

Visualize 데이터 분포를 그리는(Scatter Plot, Box Plot) 시각화 위젯군
Transform 데이터의 범위를 변경하거나 학습용/테스트용으로 섞어 나누는 위젯군
Model & Evaluate 기계학습 알고리즘(SVM, KNN, Logistic Regression) 및 평가 위젯군

🧩 3단계: Orange3 붓꽃(Iris) 분석 시뮬레이터

우측 워크스페이스에서 마우스 드래그로 위젯을 연결하여 실제 데이터 마이닝 과정을 미리 체험해봅시다.

🎮 드래그 & 연결 실습 방법:
1. **`File`** 위젯 우측에 있는 주황색 연결 포트(●)를 마우스 왼쪽 버튼으로 클릭 후 드래그합니다.
2. 점선이 나오면, 연결하고자 하는 대상 위젯(**`Data Table`**, **`Scatter Plot`**, **`Data Sampler`**)의 왼쪽 회색 포트(●)에 마우스를 뗍니다.
3. 연결선이 완성되면 위젯이 환하게 활성화됩니다. 활성화된 위젯을 클릭(터치)하시면 팝업창으로 데이터의 내용이 시각화되어 출력됩니다!

👉 File 위젯은 기본적으로 150개의 붓꽃 표본 데이터를 가집니다. 위젯들을 모두 연결하여 데이터 표와 그래프, 그리고 70% 학습 데이터 분할 정보를 직접 열람해 보세요!

🤖 이미지 임베딩 (Image Embedding) 이란?
컴퓨터는 고양이나 강아지 사진을 픽셀 그대로 분석하여 지도학습하기 어렵습니다. 구글의 합성곱신경망(CNN) 기반 모델이 이미지에서 털의 재질, 눈과 귀의 모양, 주둥이 비율 등을 분석하여 수천 개의 숫자 정보(특성 벡터, Feature Vector)로 가공해주는 기법입니다.
