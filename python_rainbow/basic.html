4 설치 셀과 준비 셀 PPT 5쪽

거북이로 그림을 그리려면 ColabTurtle을 먼저 설치해야 해요. 위쪽 설치 셀을 먼저 실행하고, 아래 준비 코드는 새 코드 셀에서 실행하세요.

설치 셀 · 먼저 실행 (한 번만)
!pip install ColabTurtle==2.2.0
준비 셀 · 설치 후 새 코드 셀(+ 코드)에서 실행
import ColabTurtle.Turtle as t
t.initializeTurtle()
t.speed(10)
실행 결과
가운데에 거북이가 나타나요. 아직 전진 명령이 없으므로 선은 그려지지 않아요.
import … as t기능을 불러와 t라는 짧은 이름으로 사용해요.
initializeTurtle()새 화면과 거북이 상태를 준비해요.
speed(10)그리는 표시 속도를 정해요. 1~13의 정수를 사용해요.
