인공지능 툴 제작 활동의 범위

5차시: 자료로 학습하는 분류

학생이 편집한 가상 학습 자료와 가까운 표본을 이용해 실제 분류 계산을 합니다. 학습 자료와 별도 테스트 자료를 구분하고, 자료 구성에 따라 결과가 달라지는 원리를 탐구합니다.

7~9차시: 프롬프트와 도구 설계

에너지 절약·분리배출·학습 계획을 주제로 입력 화면, 프롬프트, 테스트와 수정 과정을 체험합니다. 화면의 답은 준비된 규칙으로 만드는 학습용 미리보기이며 실제 생성형 AI의 응답이 아닙니다.

실제 생성형 AI와 비교할 때는 완성 프롬프트를 복사하여 학교에서 사용을 허용한 AI 도구에 직접 입력하세요. 이 시뮬레이터는 외부 AI로 입력을 자동 전송하지 않으며 API 키나 카메라를 요구하지 않습니다. 자유주제는 프롬프트 설계·점검과 외부 실행 준비를 지원합니다.

프롬프트에 포함된 요소가 많다는 이유만으로 좋은 답변이 보장되지는 않습니다. 서로 다른 입력으로 테스트하고 결과의 정확성·실용성·윤리성을 따로 확인하게 지도하세요.

수업 운영과 결과물 제출

  1. 준비: 학습 홈을 열고 1인 또는 2인 1기기로 사용합니다. 전자칠판에서는 상단 ‘전체 화면’과 ‘가＋’로 크기를 조절할 수 있습니다.
  2. 탐구: 버튼을 누르기 전에 결과를 예상하고, 조건을 바꾼 뒤 예상과 실제 결과를 비교합니다. 드래그 활동은 카드 선택 후 배치 버튼으로도 조작합니다.
  3. 기록: 서술형에는 실제 학생 이름·연락처 대신 가상의 사례를 사용합니다. 저장은 이 브라우저에만 적용되며 중앙 교사용 성적표로 자동 제출되지 않습니다.
  4. 제출: 형성평가 결과 JSON, 프로젝트 JSON, 도구 HTML, 9차시 활동 기록을 내려받아 학교에서 사용하는 과제 제출 방식으로 제출합니다. 인쇄에서 PDF 저장도 가능합니다.
  5. 이어 하기: 같은 브라우저에서 다시 열면 저장된 상태를 사용할 수 있습니다. 다른 기기로 이동할 때는 8차시에서 프로젝트 JSON을 가져오세요.
파일로 사용하는 경우 ZIP을 먼저 모두 압축 해제한 뒤 index.html을 여세요. 폴더 구조를 유지하고 화면의 차시 이동 링크를 사용하세요. 브라우저 저장이 제한된 환경에서는 결과를 내려받아 보관합니다.

제작 활동 평가 기준

교과서 220쪽 평가표에 맞춰 ‘잘함·보통·미흡’과 구체적인 근거를 함께 기록합니다. 점수의 합보다 개선 전후의 변화에 주목하세요.

과정
  1. 일상에서 실제로 발생하며 해결 가치가 있는 문제인가?
  2. 프롬프트가 구체적이고 명확한가?
  3. 성능을 평가하고 결과를 바탕으로 수정했는가?
결과
  1. 결과의 정확성을 근거로 확인했는가?
  2. 실제 문제 해결에 도움이 되는가?
  3. 개인 정보·공정성·저작권을 고려했는가?

교과서와 모형의 관계

학습 범위는 제공된 중학교 기술·가정 ② 교과서 208~220쪽의 세 소단원입니다. 원본 교과서 이미지를 화면에 재게시하지 않고, 해당 개념을 직접 조작하는 활동과 자체 도식으로 재구성했습니다. 통신 매체 비교의 수치, 가상 표본과 체험 응답은 수업용 모형이며 실제 장치의 성능이나 생성형 AI의 품질을 나타내지 않습니다.

정보 통신 기술의 ‘무한한 저장과 공유’는 확장 가능성을 강조한 교과서 표현입니다. 실제 저장 공간·요금·접근 권한에는 제한이 있음을 함께 설명합니다. 윤리 활동은 원칙과 판단을 다루며, 법률의 구체적인 형량이나 서비스의 최신 이용 조건을 단정하지 않습니다.
