정보 통신 × AI 탐구실
중학교 2학년 기술 · 교과서 208~220쪽

시작하기
1. ZIP 파일을 모두 압축 해제합니다.
2. 압축을 푼 폴더의 index.html을 Chrome 또는 Edge 등 브라우저로 엽니다.
3. 폴더 안 HTML 파일과 assets 폴더를 함께 유지합니다.
4. 화면 상단의 차시 메뉴와 하단 다음 버튼으로 이동합니다.

구성
01 정보 통신 기술의 이해: 1~3차시 + 형성평가 10문항
02 정보 통신 기술과 인공지능의 활용: 4~6차시 + 형성평가 10문항
03 인공지능 툴 제작하기: 7~9차시 + 형성평가 10문항
수업 운영안: teacher_guide.html

저장과 제출
학습 기록은 현재 브라우저에 저장합니다. 다른 기기나 브라우저로 자동 전송되지 않습니다.
각 형성평가의 결과 내려받기, 8차시 프로젝트 JSON/도구 HTML,
9차시 활동 기록 내보내기를 이용해 결과물을 보관하고 제출하세요.
다른 기기에서는 8차시에서 프로젝트 JSON을 가져올 수 있습니다.
로컬 파일 모드에서는 화면의 이동 링크로 차시를 이동하면 기록을 이어받습니다.
저장이 제한된 브라우저에서는 결과를 파일로 내려받아 보관하세요.

학습 모형 안내
5차시는 학생이 지정한 가상 표본으로 실제 3-NN 분류 계산을 수행합니다.
7~9차시 도구 제작의 응답은 규칙 기반 학습용 미리보기이며 실제 생성형 AI 응답이 아닙니다.
실제 AI와 비교하려면 완성 프롬프트를 복사하여 교사가 허용한 도구에서 직접 실행하세요.
이 자료는 외부 AI API, 계정, 카메라, 인터넷 요청 없이 핵심 활동을 실행합니다.
형성평가 결과는 교사에게 자동 전송되지 않으며 파일로 제출합니다.

제작 범위
사용자가 제공한 교과서 208~220쪽을 바탕으로 재구성한 학습 활동입니다.
교과서 원본 이미지는 배포 파일에 포함하지 않았습니다.
